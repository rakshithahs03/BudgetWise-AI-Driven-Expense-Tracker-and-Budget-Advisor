# BudgetWise – AI-Driven Expense Tracker and Budget Advisor

**BudgetWise** is a personal finance management application designed to help users track income and expenses, manage monthly budgets, monitor savings goals, and understand their financial trends through interactive visualizations.

## 📌 Overview

Managing personal finances manually can make it difficult to track spending patterns, maintain budgets, and achieve savings goals. BudgetWise provides a centralized platform for recording financial transactions, monitoring budgets and savings progress, and analyzing financial data through visual reports.

## 🚀 Key Features

* 💰 **Income & Expense Management** – Record and manage income and expense transactions.
* 📝 **Transaction CRUD Operations** – Create, view, update, and delete financial records.
* 🏷️ **Categorized Transactions** – Organize transactions based on categories.
* 📜 **Transaction History** – View previously recorded income and expense transactions.
* 💵 **Monthly Budget Tracking** – Set and monitor monthly spending budgets.
* 🎯 **Savings Goal Tracking** – Create savings goals and monitor progress.
* 📊 **Budget Progress Monitoring** – Track remaining budgets and spending progress.
* 📈 **Financial Data Visualization** – Analyze financial data using charts and graphical reports.
* 📅 **Monthly Spending Analysis** – Compare income and expenses across different months.

## 🔄 Application Workflow

1. User records an income or expense transaction.
2. The transaction is categorized and stored.
3. Users can view, edit, or delete existing transactions.
4. Monthly budgets are configured and monitored.
5. The system calculates remaining budget based on recorded expenses.
6. Users create and monitor savings goals.
7. Financial data is presented through charts and monthly comparisons.

## 📊 Financial Visualization
